# Release notes for Statik.be's Craft scaffolding package

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/) and this project adheres to [Semantic Versioning](http://semver.org/).

Releases are tagged in git. From the Rectangle release on, the full release notes are in [WHATS-NEW.md](WHATS-NEW.md); this file keeps a short summary per release.

## Unreleased: Rectangle

The content builder is rebuilt around content rows (the Trinity plugin), with native Link fields instead of Hyper, the Entry Anchors, Headings Checker and Link Checker plugins, a token-based theme, a new template folder structure in `templates/_site/` and translations in git. Requires Craft 5.12 and PHP 8.4. See [WHATS-NEW.md](WHATS-NEW.md) for everything that changed and how to update a project.

## 5.15.0 - 2026-10-29

### Added

- Redis as the cache in production (`yiisoft/yii2-redis`, `REDIS_HOSTNAME`, `REDIS_PORT`, `REDIS_PASSWORD`), with a default TTL of one day per cache entry
- Sessions are stored in Redis in production (Redis database 1, so clearing the cache doesn't log everyone out)
- Persistent database connections in production
- Compiled templates and classes can be moved out of the release folder with `CRAFT_COMPILED_PATH` (new `storage/appcache` folder, writable on deploy)
- Schema.org markup on the news detail and news overview pages
- After a Formie form is submitted, the page scrolls to the success message

### Updated

- htaccess hardening (`public/.htaccess` and `config/htaccess-production`): requests without a User-Agent, WordPress scanner paths and dotfiles (except `/.well-known/`) are blocked before they reach Craft
- `config/robots-production` blocks a few more bots (SumbleBot, IbouBot, MachineWitnessBot, CCBot)
- `deploy.php` uses `ssh.bitbucket.org` as the Bitbucket SSH hostname

### Fixed

- Searching with accented letters returned all results; search validation now accepts every Unicode letter (#653)
