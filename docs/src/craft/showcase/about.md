# Content builder showcase

The showcase is a tree of pages in the **Pages** section that shows every column type of the content row, in every layout
and next to every other column type, with every field variant. Designers, developers and testers use it to check a theme or
a change to a column type without building test pages by hand.

The pages are generated by a console command (see [Generating it](./generating)), so new or changed column types show up
without code changes. Remove them before a project goes live (see [Removing it](./removing)).

## The pages

The parent page has the slug `gridbuilder` (`gridbuilderShowcaseSlug` in `config/custom.php`), at the root of the Pages
section.

| Page                                                   | What it shows                                                                                                                                                                  |
| ------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `gridbuilder`                                          | Cards to every column type, the Layouts page, the 2/3 page and the 3/4 page                                                                                                     |
| `gridbuilder/<type>` (e.g. `gridbuilder/text`)         | Cards to the combination of that column type with every column type, itself included                                                                                            |
| `gridbuilder/<type>/<type>-<type>`                     | Two column types next to each other: every layout they fit in, both ways round, and each one first on mobile. The same type twice: the type alone in every layout, and its variants at 1/2 next to the base variant |
| `gridbuilder/layouts`                                  | Every layout with neutral cells, every vertical alignment, and a row with a mobile order                                                                                       |
| `gridbuilder/two-thirds-page`, `gridbuilder/three-quarters-page` | Every column type in the layouts allowed when the content builder is that wide, like a page with a sidebar                                                           |

A combination page sits under the column type that comes first in the cells field: the "Image" page links to "Text + Image",
which is under "Text". Row backgrounds rotate over the rows, so every background shows up.

### Variants

Which fields of a column type vary, and over which values, is decided per field type:

| Field                                                                 | Variants                                             |
| --------------------------------------------------------------------- | ---------------------------------------------------- |
| Option fields (Position, Width, Config Values, Dropdown, Radio Buttons, Button Group) | One per option                        |
| Lightswitch                                                           | On and off                                           |
| Matrix with a minimum and maximum number of entries                   | One per number of entries                            |
| Entries                                                               | 3, 2 and 1 entries, plus 0 when the field is optional |
| Any other optional field                                              | Filled and empty                                     |
| Required fields                                                       | Always filled                                        |

Variants that a column's "Column width" field condition hides at a width aren't shown at that width.

### The variation label

On a showcase page, `contentBuilder.twig` writes an HTML comment before each block that describes its variation, e.g.
`<!-- Contentbuilder variation: "#3 · …" -->`. It isn't rendered, so the page output stays the same as on a real page.
Search the page source for it when you need to know which variant you're looking at.

## The 2/3 and 3/4 pages

These two pages render the content builder narrower than the page, like a page with a sidebar. The module tells Trinity the
page width through `Rows::EVENT_DEFINE_PAGE_WIDTH` and registers the two widths with `Rows::EVENT_REGISTER_PAGE_WIDTHS`, so
the content rows on them follow the width rules for that width. `contentBuilder.twig` wraps the builder in a `lg:w-2/3` or
`lg:w-3/4` container.

| Slug                    | Width |
| ----------------------- | ----- |
| `two-thirds-page`       | 2/3   |
| `three-quarters-page`   | 3/4   |

## Twig helpers

The showcase code in `contentBuilder.twig` uses three methods of the [`craft.statik` variable](../twig/statik-variable):

| Method                                  | Returns                                                                                      |
| --------------------------------------- | -------------------------------------------------------------------------------------------- |
| `isContentbuilderShowcasePage(page)`    | Whether the page is in the showcase tree (below the `gridbuilder` page in the Pages section) |
| `showcasePageWidth(page)`               | `0.6667` or `0.75` on the 2/3 and 3/4 pages, `null` on every other page                      |
| `contentbuilderShowcaseLabel(block)`    | The description of the block's variation, used in the HTML comment                           |

```twig
{% set isShowcase = craft.statik.isContentbuilderShowcasePage(entry) %}
{% set showcasePageWidth = isShowcase ? craft.statik.showcasePageWidth(entry) : null %}
```

This code sits between `{# contentbuilder-showcase:start #}` and `{# contentbuilder-showcase:end #}` markers, so it can be
removed in one go.
