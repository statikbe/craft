# What's new and changelog

Two files in the repo keep track of what changed in the base install.

| File | What's in it |
| ---- | ------------ |
| [WHATS-NEW.md](https://github.com/statikbe/craft/blob/develop/WHATS-NEW.md) | What changed per release, newest first: what's new, how it works, and what was removed or replaced. Start here when you update a project or start a new one. |
| [CHANGELOG.MD](https://github.com/statikbe/craft/blob/develop/CHANGELOG.MD) | The older release notes, up to 3.1.6 (January 2023), in the [Keep a Changelog](https://keepachangelog.com/) format. |

Small fixes and version bumps are left out of both: see the
[Git history](https://github.com/statikbe/craft/commits/develop) for those.

Frontend changes reach existing projects as Clint updates: see [Updates](/frontend/clint/updates).
